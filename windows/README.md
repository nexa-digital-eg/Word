# تشغيل البرنامج على ويندوز 🪟

ثلاث ملفات جاهزة بالنقر المزدوج (Double-click):

| الملف | الوظيفة |
|------|---------|
| **`install.bat`** | يثبّت البرنامج وكل مكتباته (شغّله **مرة واحدة** أول مرة) |
| **`run.bat`** | يفتح **الواجهة الرسومية** للبرنامج |
| **`convert_drag_drop.bat`** | **اسحب ملف PDF وأفلته** عليه ليحوّله مباشرة |

## الخطوات

### 1) ثبّت بايثون (مرة واحدة)
حمّله من <https://www.python.org/downloads/>
> ⚠️ مهم: فعّل خيار **"Add Python to PATH"** أثناء التثبيت.

### 2) ثبّت محرّك OCR للعربية (مُوصى به بشدة)
حمّل Tesseract من
<https://github.com/UB-Mannheim/tesseract/wiki>
واختر **اللغة العربية (Arabic)** أثناء التثبيت، ثم أعد تشغيل الجهاز.
> بدونه يعمل وضع `text` فقط (أسرع لكنه قد لا يحافظ على العربية في كل الملفات).

### 3) ثبّت البرنامج
انقر نقراً مزدوجاً على **`install.bat`** وانتظر حتى تظهر رسالة "تم التثبيت بنجاح".

### 4) استخدم البرنامج
- للواجهة الرسومية: انقر **`run.bat`**
- أو اسحب ملف PDF وأفلته على **`convert_drag_drop.bat`**

ملف الوورد الناتج يُحفظ بجوار ملف الـ PDF الأصلي بنفس الاسم.
