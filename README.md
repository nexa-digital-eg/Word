# محوّل PDF إلى Word مع دعم العربية 📄➡️📝

برنامج يحوّل ملفات **PDF** إلى **Word (.docx)** مع الحفاظ على **النص العربي سليماً
بجميع أنواع الخطوط** — بحيث لا "يبوظ" التحويل ولا ينعكس النص أو يتقطّع.

## ✨ المميزات

- **دعم كامل للعربية** بأي خط (نسخ، كوفي، رقعة، خطوط مخصّصة...).
- **ثلاثة محرّكات للتحويل**:
  | المحرّك | الوصف | متى تستخدمه |
  |--------|-------|------------|
  | `ocr` | يعيد قراءة الصفحة كصورة عبر Tesseract | **الأكثر موثوقية للعربية** — لا يعتمد على ترميز الـ PDF فلا يتلف النص مهما كان الخط (الأبطأ) |
  | `text` | يستخرج طبقة النص مباشرة | الأسرع، للملفات ذات النص القابل للنسخ والسليم |
  | `auto` | **(الافتراضي)** يختار الأنسب لكل صفحة | يكتشف النص التالف/الممسوح ضوئياً ويتحول إلى OCR تلقائياً |
- ضبط **اتجاه RTL** والمحاذاة لليمين تلقائياً في ملف الوورد.
- معالجة المحارف التالفة حتى لا يفشل إنشاء الملف.
- **واجهة رسومية** (Tkinter) + **واجهة سطر أوامر** + **مكتبة بايثون**.
- تحويل عدة ملفات دفعة واحدة.

## 🧠 لماذا الـ OCR هو الخيار الموثوق للعربية؟

كثير من ملفات الـ PDF تخزّن العربية على هيئة **أشكال تقديمية بترتيب بصري معكوس**.
عند الاستخراج المباشر للنص تظهر الحروف مقلوبة أو مقطّعة (مثل `ﻢﻴﺣﺮﻟﺍ` بدل `الرحيم`).
محرّك الـ OCR يتجاوز هذه المشكلة لأنه **يقرأ شكل الصفحة كصورة** ثم يتعرّف على
الحروف، فينتج نصاً عربياً صحيحاً بالترتيب المنطقي مهما كان الخط المستخدم.
لذلك يكتشف وضع `auto` هذه الأشكال التقديمية ويتحوّل إلى الـ OCR تلقائياً.

## 📦 المتطلبات

### 1) محرك Tesseract OCR (لمحركي `ocr` و`auto`)

- **Ubuntu / Debian:**
  ```bash
  sudo apt-get install tesseract-ocr tesseract-ocr-ara poppler-utils
  ```
- **macOS:**
  ```bash
  brew install tesseract tesseract-lang
  ```
- **Windows:** حمّل المثبّت من
  [UB-Mannheim/tesseract](https://github.com/UB-Mannheim/tesseract/wiki)
  واختر اللغة العربية أثناء التثبيت، ثم أضف مساره إلى `PATH`.

### 2) مكتبات بايثون

```bash
pip install -r requirements.txt
```

## 🚀 الاستخدام

### واجهة سطر الأوامر

```bash
# تحويل ملف واحد (الوضع الذكي auto)
python -m pdf_to_word ملف.pdf

# تحديد اسم الإخراج والمحرّك
python -m pdf_to_word ملف.pdf -o الناتج.docx --engine ocr

# أقصى دقة للعربية
python -m pdf_to_word ملف.pdf --engine ocr --dpi 400

# تحويل عدة ملفات
python -m pdf_to_word *.pdf --engine auto
```

| الخيار | الوصف | الافتراضي |
|-------|-------|----------|
| `-o, --output` | مسار ملف الإخراج (لملف واحد) | بجوار الأصل |
| `--engine` | `auto` \| `ocr` \| `text` | `auto` |
| `--lang` | لغات الـ OCR | `ara+eng` |
| `--dpi` | دقة العرض عند الـ OCR | `300` |
| `--font` | خط مستند الوورد | `Arial` |
| `--font-size` | حجم الخط | `12` |

### الواجهة الرسومية

```bash
python -m pdf_to_word.gui
```

### كمكتبة في كودك

```python
from pdf_to_word import PdfToWordConverter, ConversionOptions

converter = PdfToWordConverter(ConversionOptions(engine="ocr", dpi=400))
result = converter.convert("input.pdf", "output.docx")
print(result.output_path, result.page_count)
```

## ⚠️ ملاحظات

- المحرّك `ocr` ينتج **نصاً قابلاً للتحرير** لكنه لا يحافظ على التنسيق المعقّد
  (جداول/أعمدة) بدقة 100٪؛ الأولوية فيه لسلامة النص العربي.
- لرفع دقة الـ OCR على المستندات الصغيرة الخط، استخدم `--dpi 400` أو أعلى.
- تأكد من تثبيت حزمة اللغة العربية لـ Tesseract (`tesseract-ocr-ara`).
